# Day 21 - LocalStorage, JSON, Forms and Regex

Day 21 focuses on using localStorage, JSON, forms, validation, and regular expressions in JavaScript.

## Files

### Exercises

    exercise.html
    exercise.js

### Mini-Project

    index.html
    app.js

## Exercises

The exercises cover:

- Saving and restoring a theme using localStorage
- Creating save() and load() helpers
- Converting arrays to JSON
- Parsing JSON from localStorage
- Handling null and corrupt storage data
- Creating a signup form
- Reading and trimming form values
- Validating a name
- Validating an Ethiopian phone number
- Displaying clear error messages with textContent
- Saving valid signup entries to localStorage
- Restoring saved entries after reload
- Displaying the number of registered people

## Mini-Project

The mini-project is a validated and persistent signup form.

The form accepts a full name and an Ethiopian phone number. It validates the input and saves valid entries to localStorage as JSON.

### Features

- Labelled name input
- Labelled phone input
- Submit button
- Dedicated error area
- Form validation
- Ethiopian phone number validation with regex
- Clear error messages
- localStorage persistence
- JSON serialization
- Saved data restored after page reload
- Null storage handling
- Corrupt JSON handling

## How to Run

Open the HTML file in a web browser.

For the exercises, open:

    exercise.html

For the mini-project, open:

    index.html
