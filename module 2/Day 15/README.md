# Habesha Eatery – Responsive & Animated Menu

## Overview

This project is a responsive menu section for Habesha Eatery.

The menu uses a mobile-first layout and adapts to different screen sizes.

## Features

- One column on mobile
- Two columns from 768px
- Three columns from 1024px
- Responsive menu cards
- Smooth hover transition
- TranslateY and scale hover effect
- Reduced-motion accessibility support
- Responsive ingredient tags
- ETB price labels
- Viewport meta tag

## Responsive Breakpoints

Mobile uses one column.

At 768px, the menu changes to two columns.

At 1024px, the menu changes to three columns.

## Animation

Each menu card uses a smooth transition.

When the user hovers over a card, it moves upward and becomes slightly larger.

## Reduced Motion

The project uses `prefers-reduced-motion` to disable the animation for users who prefer reduced motion.
