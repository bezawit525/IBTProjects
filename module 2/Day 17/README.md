# Day 17 – JavaScript Functions, Closures & Higher-Order Functions

## Overview

This repository contains my **IBT College Canada CodeOps Module 2 Day 17** work, including JavaScript exercises and two projects focused on functions, closures, higher-order functions, and pure functions.

## Exercise: JavaScript Functions

Created `exercise.js` to practice:

- Default parameters
- Arrow functions with implicit returns
- Closures
- Function factories
- Higher-order functions
- `map()` and `forEach()`
- Callback functions
- Pure functions

The exercises include a VAT calculator, private counter, discount factory, higher-order function, and Ethiopian city list.

File:

- `exercise.js`

## Project: Loyalty Points Module

Built a loyalty-points module for a TeleBirr shop using:

- Closures for private points balance
- `earn()` for adding points
- `redeem()` for subtracting points
- `balance()` for checking points
- Higher-order functions for flexible earning rules
- A holiday rule for double points

The points balance remains private and can only be accessed through the provided functions.

File:

- `loyalty.js`

## Project: ETB Order Receipt Maker

Built an order receipt module that calculates prices in ETB using:

- reduce() to calculate the subtotal
- A discount factory for member discounts
- A VAT helper
- An ETB formatting helper
- A closure-based receipt maker with a private running order number
- Pure functions and function composition

Files:

- `order.js`
