# Day 01 Notes

## Five Terminal Commands

### 1. pwd
Shows the current directory I am working in.

### 2. ls
Lists the files and folders in the current directory.

### 3. cd
Changes from one directory to another.

### 4. mkdir
Creates a new folder.

### 5. touch
Creates a new empty file.



## Three Git Commands

### 1. git status
Shows the current state of the repository and any changes.

### 2. git add .
Stages all changed files so they are ready to be committed.

### 3. git commit -m "message"
Creates a snapshot of the staged changes with a descriptive message
